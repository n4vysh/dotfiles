# keyd

| Physical key    | Mapped To       | Note                                          |
| :-------------- | :-------------- | :-------------------------------------------- |
| `Capslock`      | N/A             |                                               |
| `Alt (Right)`   | `Ctrl (Right)`  | `Escape` when pressed alone like xcape        |
| `Alt (Left)`    | `Alt (Left)`    |                                               |
| `Shift (Right)` | `Shift (Right)` | `(` when pressed alone like space cadet shift |
| `Shift (Left)`  | `Shift (Left)`  | `)` when pressed alone like space cadet shift |
