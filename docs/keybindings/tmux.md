# Tmux

prefix is `C-j`

| root         | `C-l` | Switch last window                                     |

| root         | `C-v` | Create a new pane by horizontal split                  |

| root         | `C-m` | Show manual                                            |
| root         | `e`   | Edit config of tmux                                    |
