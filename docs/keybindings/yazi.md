# yazi

| Keys      | Description                     |
| :-------- | :------------------------------ |
| `g` + `r` | Goto git root directory         |
| `,` + `d` | Diff for selection items        |
| `,` + `e` | Open editor                     |
| `,` + `l` | Show git log for selection item |
| `,` + `T` | Restore trashed files           |
| `,` + `u` | Show disk usage                 |
| `,` + `v` | Open git client                 |
